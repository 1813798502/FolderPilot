# 文件夹管家

一个基于 Python + Tkinter 的 Windows 常用项目管理工具，可以收藏文件夹、文件与启动脚本，无需安装第三方依赖。

## 启动

双击 `启动文件夹管家.cmd`。启动器默认使用 `D:\python\pythonw.exe`，运行时不会出现额外的命令行窗口。

也可以在命令行中运行：`python folder_pilot.py`。

## 安装包

运行 `FolderPilot-Setup-2.0.1.exe` 后即可在其他 64 位 Windows 电脑上使用，目标电脑不需要安装 Python。安装时会明确显示路径选择页面，可以安装到 D 盘或其他位置，并会记住上次的安装目录。安装程序可以创建桌面和开始菜单快捷方式，并提供标准卸载入口。

## 功能

- 添加、编辑和移除常用文件夹（移除不会删除真实文件夹）
- 添加普通文件及 `.bat`、`.cmd`、`.ps1`、`.py`、`.vbs` 等启动脚本
- 文件使用 Windows 默认应用打开，PowerShell 与 Windows Script Host 脚本可直接运行
- 名称前显示 Windows 原生图标：文件夹图标、软件自身图标或文件关联图标
- 点击列表中的“分类”单元格，可以直接从下拉菜单更换分类
- 支持把文件夹、文件或脚本直接拖进窗口
- `Ctrl+Alt+Space` 全局呼出窗口并定位到搜索框
- 关闭窗口后进入系统托盘，托盘菜单显示最近使用项目
- 右键菜单支持打开所在位置、复制路径、分类、置顶和修复路径
- 导入、导出完整数据，并自动保留最近 10 份修改前备份
- 启动脚本首次运行确认，可按项目设置信任
- Ctrl/Shift 多选后批量分类、置顶或移除
- 自动提供“最近使用”和“最常使用”视图
- 支持别名、备注和搜索关键词
- 记忆窗口位置、大小、列宽、排序和最后分类
- 单实例运行并适配 Windows 高分屏缩放
- 左上角“帮助”内置完整操作和快捷键说明
- 按名称、路径、分类和备注搜索
- 自定义分类与置顶
- 独立管理分类：新增、重命名、删除，空分类也会保留
- 删除分类时，其中的常用项目会安全移动到“未分类”
- 双击或按 Enter 打开所选项目
- 按最近打开、使用次数或名称排序
- 自动标记已移动或删除的失效路径
- `Ctrl+F` 快速进入搜索框

## 数据位置

数据保存在 `%LOCALAPPDATA%\FolderPilot\folders.json`，只存在当前电脑。备份或迁移时复制这个文件即可。
